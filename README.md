# Sima Bagheri — GitHub Pages website

A minimal salmon-toned personal academic website and blog. No framework or build step required.

## Publish on GitHub Pages
1. Create a **public** repository named `YOUR-USERNAME.github.io` (replace with your actual GitHub username).
2. Upload **the contents of this folder** to the repository root (not the enclosing folder), and commit.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and save.
4. Visit `https://YOUR-USERNAME.github.io/`. Deployment may take a few minutes.

## Add your picture
Put your portrait at `assets/images/profile.jpg` (exact name and extension). Until then, the page displays a placeholder.

## Add presentation PDFs
Place `Sima_WARP_ICC.pdf` and `Steering_Sima.pdf` in `assets/pdf/`. Links are present but won't work until these files are added.

## Add a new blog post
Copy `posts/less-psychology-more-philosophy.html`, rename it (e.g. `my-new-post.html`), replace the article's content and title, then add a corresponding link/card to `blog.html`.

## Customize colors
Edit the CSS variables at the top of `style.css`. `--bg` controls the light salmon background; `--salmon` is the accent; `--ink` is text.

The blog post is lightly copyedited for readability, with its argument and personal voice retained. Publication statuses and older biographical claims were kept as supplied; review before publishing.
